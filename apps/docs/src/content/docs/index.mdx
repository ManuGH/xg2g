## Quick Start (Docker Compose)

Deploy in seconds on any Linux host with Docker:

```yaml
services:
  xg2g:
    image: ghcr.io/manugh/xg2g:latest
    container_name: xg2g
    restart: unless-stopped
    ports:
      - "8088:8088"
      - "9091:9091"
    environment:
      - XG2G_E2_HOST=http://enigma2.local
      - XG2G_DECISION_SECRET=super-secret-decision-signing-key-min-32-bytes
      - XG2G_STREAM_PASSTHROUGH=true
      - XG2G_METRICS_LISTEN=:9091
```

> 💡 **Custom Hardware & Deployment Generator:** Try the **[Interactive Deployment Configurator & Codec Calculator](/xg2g/guides/configurator/)** to generate custom Docker CLI, VAAPI / NVENC, or Linux systemd configurations with live transcode decision simulation.
