Visual Experience

Built for Browsers, Mobile and Smart TVs

Zero-app delivery for live broadcasts and recordings. Instant stream startup with adaptive remuxing, tuner lease governance, and full EPG timeline scrub.

Operator Dashboard

Active Sessions & Tuner Lease Arbitration

Real-time visibility into running client sessions (Chromium hls.js, iPad Safari Native HLS), receiver connection health, and automatic tuner arbitration preventing tuner lockups.

Live TV Guide

Browse satellite and cable bouquets directly in any browser. Supports live timeline progress, favorites filtering, and one-click playback without external player plugins.

Fast Deployment

Get Running in Minutes

Choose between a standalone Docker container for immediate evaluation or the automated Linux host installer for dedicated systemd production service.

Docker Run (Evaluation) 
docker run -d --name xg2g --restart unless-stopped \
  -p 127.0.0.1:8088:8088 \
  -e XG2G_E2_HOST="http://192.168.1.10" \
  -e XG2G_API_TOKEN="$(openssl rand -hex 32)" \
  -e XG2G_API_TOKEN_SCOPES="v3:admin" \
  -e XG2G_DECISION_SECRET="$(openssl rand -hex 32)" \
  ghcr.io/manugh/xg2g:v3.12.0
Guided Host Setup 
# Guided Linux persistent install
git clone https://github.com/ManuGH/xg2g.git
cd xg2g
sudo ./infra/systemd/setup-linux.sh

# Verify daemon readiness
curl -fsS http://localhost:8088/readyz
